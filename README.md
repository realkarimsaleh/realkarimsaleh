# Hey, I'm Karim 🐼

I'm all about writing beautiful code, building disruptive software, making good friends, maintaining relationships & enjoying my limited time on this planet.

Most of my time goes into device provisioning, endpoint management and automation, building tools that make that work faster, and tinkering with my homelab.

## What I build
- **PandaTools** - a C# (.NET) and PowerShell toolset for day-to-day IT work
- **PandaFences** - a desktop icon organiser with Git-synced layouts
- **WinForms utilities** - GUI tools for imaging, device enrolment and diagnostics
- **Homelab automation** - Proxmox, Ansible and Packer across a mix of servers and a Pi cluster
